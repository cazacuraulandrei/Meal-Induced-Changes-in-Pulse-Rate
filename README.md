# Meal-Induced Changes in Pulse Rate

## Project Aim

This project investigates whether pulse rate changes before and after eating a meal, and whether factors such as sex and meal size may influence this change.

## Dataset

The dataset contains anonymous pulse measurements from 175 participants collected before and after a meal.

Rows with missing data were removed prior to analysis, resulting in 170 participants included in the final analysis.

## Methods

* Data analysis performed in Python
* Used pandas for data manipulation and cleaning
* Used scipy for statistical testing (paired t-test)
* Used matplotlib for data visualisation

## Analysis

* Compared pre-meal and post-meal pulse rates
* Performed a paired t-test to assess statistical significance
* Explored pulse rate differences by sex and relative meal size

## Key Results

There was a statistically significant increase in pulse rate after meals (p < 0.001).

Descriptive subgroup analysis suggested pulse rate increased in both males and females, and across all meal-size categories.

## Tools

* Python
* pandas

## Summary

This project demonstrates basic exploratory data analysis, statistical testing, data cleaning and visualisation using physiological data.
